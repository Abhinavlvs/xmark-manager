# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting ("Report a vulnerability" under the repository's Security tab). We aim to acknowledge reports within 7 days.

## Scope

xmark-manager requests only `storage`, `activeTab`, and access to `x.com` / `twitter.com`. It loads no remote code and sends no data to the developer or anywhere else (Phase 1 makes no network requests; Google Drive sync is a Phase 2 item).
